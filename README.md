# SUK Bingo

Bingo a eventi da giocare con gli amici: tabelloni 5×5 personalizzati, link di invito, caselle segnate in tempo reale e animazione del BINGO.

Sito statico (GitHub Pages) con Firebase Authentication (Google, email/password) e Firestore. Istruzioni di configurazione in [ISTRUZIONI.md](ISTRUZIONI.md).
